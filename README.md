# Códigos en C 🖥️ / C Projects Collection 🖥️

Una colección curada de proyectos de programación en **C** por **Iris Jasso**, que van desde ejercicios fundamentales hasta temas avanzados como manejo de memoria dinámica, interfaces gráficas con GTK y graficado de datos. Cada proyecto está diseñado para mostrar habilidades prácticas de programación y conceptos clave de C.  

A curated collection of **C programming projects** by **Iris Jasso**, ranging from fundamental exercises to advanced topics such as dynamic memory management, GTK-based graphical interfaces, and graph plotting. Each project is designed to showcase practical C programming skills and core C concepts.

---

## Proyectos / Projects 📂

- **Ecuaciones 📝 / Equations** – Programas para resolver ecuaciones algebraicas y numéricas en C. / Programs solving algebraic and numerical equations in C.  
- **Fundamentos/P2023 🔹 / Fundamentals/P2023** – Ejercicios básicos de programación 2023, incluyendo bucles, condicionales y arreglos. / Basic programming exercises for 2023, covering loops, conditionals, and arrays.  
- **Fundamentos0 🔹 / Fundamentals0** – Programas introductorios en C enfocados en variables y estructuras de control. / Introductory C programs focusing on variables and control structures.  
- **Modelado 📊 / Modeling** – Programas de modelado y simulación, algunos con salida gráfica. / Modeling and simulation programs in C, some with graphical output.  
- **PENTE 🎮** – Implementación del juego PENTE en C. / Implementation of the PENTE game in C.  
- **ProgAp 💻 / Applied Programming** – Proyectos de programación aplicada para demostrar habilidades prácticas. / Applied programming projects demonstrating practical skills.  
- **cositas ✨ / Miscellaneous** – Ejercicios varios, algunos con interfaces GTK y salidas gráficas. / Miscellaneous exercises, some including GTK interfaces and graphical outputs.  
- **Ecuaciones_diferenciales 📈 / Differential Equations** – Programas para resolver ecuaciones diferenciales, algunos con visualización gráfica usando GTK. / Programs solving differential equations, some with graphical visualization using GTK.

## Instalación / Installation ⚙️

1. Clona el repositorio / Clone the repository:  
   bash
   git clone https://github.com/YIJ18/Codigos-en-C.git


2. Accede a la carpeta de un proyecto / Navigate to a project folder:

   bash
   cd NombreDelProyecto / cd ProjectName
   
3. Compila el programa / Compile the program:

   bash
   gcc programa.c -o programa / gcc program.c -o program
   
4. Ejecútalo / Run it:

   bash
   ./programa / ./program
